# History: the Mesh specs and plans

Everything in this folder was written while the product was called **Mesh**.
It is now **Aflos** (Afrikaans for "relay"). These files are kept as they were
written, as the record of how each part was designed: read "Mesh" as Aflos,
and `mesh-app`, `mesh-core`, `mesh-discord`, `mesh-dc`, `mesh-wa` and
`mesh-media` as `aflos`, `aflos-core`, `aflos-discord`, `aflos-dc`, `aflos-wa`
and `aflos-media`.

What still says "mesh" on purpose: the network engine `mesh-node` (the
Mesh-Node repo), `mesh1…` IDs, `mesh://` links and `.mks` backups. Renaming
those would break existing identities, friend codes and backups.
