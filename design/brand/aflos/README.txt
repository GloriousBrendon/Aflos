AFLOS LOGO PACK
===============

svg/      Vector files, one folder per colour version. Text is converted to outlines.
png/      Transparent PNGs (lockups 2000 px wide, mark 1024 px wide).
icons/    App icons (SVG + PNG sizes 16-1024) and favicon.ico.
social/   GitHub social preview (1280x640) and README banner (1600x400).
font/     Michroma Regular, the wordmark font (SIL Open Font License).
colors.json  The colour values used.

COLOUR VERSIONS
  dark   Rose and grey-blue. For dark backgrounds (#0f1822 or #080c10). Main version.
  light  Darker rose and grey-blue. For white or light backgrounds.
  white  One colour, white. For photos and dark single-colour printing.
  black  One colour, black. For light single-colour printing, stamps, fax-style use.

LOCKUPS
  horizontal               Mark + AFLOS + tagline
  horizontal-no-tagline    Mark + AFLOS
  stacked                  Mark above AFLOS + tagline
  stacked-no-tagline       Mark above AFLOS
  wordmark                 AFLOS only
  mark                     The jack mark only

USAGE NOTES
  - Use the tagline only when the logo is wider than about 300 px. Below that, use a no-tagline version.
  - Below about 64 px, use the mark or the icon.
  - Keep clear space around the logo of at least the height of one jack ring.
  - The dark version on white fails contrast (about 2.5:1). Use the light version there.
  - icons/aflos-icon-dark-square is full-bleed, for avatars that crop to a circle.
